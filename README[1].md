# Bloodmoon Store

Ilova, oʻyin va kitoblar doʻkoni. Sayt va server bitta joyda (Node.js + PostgreSQL).

## Render'da ishga tushirish (terminalsiz)

1. Bu fayllar GitHub'dagi repository'da turishi kerak.
2. render.com ga GitHub orqali kiring.
3. **New** → **Blueprint** → shu repository'ni tanlang → **Apply**.
4. Bir necha daqiqadan keyin Render `...onrender.com` manzilini beradi. Doʻkon shu manzilda ochiladi.

## Muhim

- Tekin tarifda server 15 daqiqa jim turgach uxlaydi, birinchi ochilishi taxminan 1 daqiqa oladi.
- Tekin tarifda yuklangan fayllar server qayta ishga tushganda yoʻqolishi mumkin, tekin baza esa 30 kundan keyin tugaydi. Bu faqat sinov uchun.
- Toʻlov hozir test rejimida (pul yechilmaydi). Haqiqiy Payme va Uzum Bank hali ulanmagan.
